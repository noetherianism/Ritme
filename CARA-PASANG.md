# Cara pasang Ritme

1. Unduh APK dari [halaman Releases](https://github.com/noetherianism/Ritme/releases/latest).
2. Buka berkas APK di HP Android 8 atau lebih baru.
3. Bila Android meminta izin memasang dari sumber ini, berikan hanya untuk aplikasi yang Anda pakai membuka APK.
4. Buka Ritme dan pilih izin notifikasi agar pengingat dapat muncul. Izin lokasi dan akses notifikasi bank bersifat opsional.

Unduh APK hanya dari halaman GitHub ini. Nilai SHA-256 berkas dicantumkan pada catatan setiap versi agar Anda dapat memeriksa berkas yang diunduh.

## Bila sudah memakai versi debug

APK publik memakai tanda tangan berbeda. Android tidak akan memasangnya sebagai pembaruan langsung atas Ritme debug.

1. Buka Ritme debug dan buat backup terenkripsi dari menu Lainnya. Simpan berkas dan kata sandinya di tempat aman.
2. Pastikan berkas backup dapat ditemukan sebelum menghapus aplikasi debug.
3. Hapus aplikasi debug dari HP, lalu pasang APK publik.
4. Buka Ritme publik dan pulihkan backup dari menu Lainnya.
5. Periksa kegiatan, transaksi, dan saldo setelah pemulihan.

Menghapus aplikasi debug tanpa backup akan menghapus data lokalnya. Jika ragu, pertahankan aplikasi yang sekarang sampai backup berhasil dibuat.

## Pembaruan berikutnya

Unduh versi baru dari halaman Releases dan pasang di atas versi publik sebelumnya. Selama tanda tangan tetap sama, data aplikasi tidak perlu dihapus. Jangan menghapus aplikasi untuk mengatasi pesan gagal pasang sebelum penyebabnya diperiksa.
